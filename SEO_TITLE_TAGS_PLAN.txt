=====================================================================
HOW IT WILL WORK
=====================================================================
  1. New optional field "SEO Title" (meta_title, max 70 chars) on
     products, categories, sub-categories and brands, editable in the
     admin edit forms with a live character counter (aim 50-60).
  2. Page <title>: uses the SEO Title when filled; otherwise the current
     automatic title (so new items still get a sensible title).
  3. Home + /shop titles: set in the page templates (below).
  4. One migration fills in all titles from this list:
       - categories / sub-categories / brands: matched by exact slug.
       - products: the sheet cuts product URLs short (e.g.
         "niacinamide-ultra-"), so each product is matched by its slug
         START plus its product NAME. Rows that match 0 or 2+ products are
         skipped and printed in the migration output so you can set them
         by hand in admin. Nothing else is changed.
     Re-running is safe; it only sets titles, never slugs or names.
  5. Titles you later edit in admin are never overwritten by the migration.
