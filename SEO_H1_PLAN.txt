=====================================================================
HOW IT WILL WORK
=====================================================================
  1. New optional field "H1 Heading" (h1_heading, max 120 chars) on
     products, categories, sub-categories and brands, in the admin add/edit
     forms next to SEO Title / Meta Description.
  2. Exactly ONE <h1> per page:
       - Product page: the product name heading becomes an <h1> (same look),
         text = H1 Heading if set, otherwise the product name.
       - Category / sub-category / brand pages: the existing <h1> shows the
         H1 Heading if set, otherwise the name (as now). A brand inside a
         category (e.g. /hair-care?brand=misumi) keeps "Misumi Hair Care".
       - /shop: "All Products" (search pages keep "Shop Our Products").
       - Home: add an <h1> "Herbal Beauty & Personal Care, Made in Sri
         Lanka" in the hero. The hero is a full-width image slider, so the
         heading is placed for search engines / screen readers without
         covering the banner (visually hidden). See NOTE 1.
  3. Breadcrumbs keep the short names; only the <h1> text changes.
  4. One migration fills the H1s into EMPTY fields only, matching products
     exactly like the titles (slug start + name). php artisan seo:titles
     reports H1s too. Values edited in admin are never overwritten.
